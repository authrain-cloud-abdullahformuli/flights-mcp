## Becoming a Contributor

Find Flights MCP Server welcomes open-source contributors! To contribute:
1. Fork the repository (`authrain-cloud-abdullahformuli/flights-mcp`)
2. Create your feature branch (`git checkout -b feature/cool-feature`)
3. Commit your enhancements
4. Open a Pull Request
